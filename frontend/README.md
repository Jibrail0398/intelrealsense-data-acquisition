# Frontend — RealSense Collector

Vue 3 + TypeScript + Vite + Tailwind CSS 4 + shadcn-vue (reka-ui) + Pinia.

Instalasi, cara menjalankan dan struktur proyek ada di [README utama](../README.md).

```bash
npm install
npm run dev          # http://127.0.0.1:5173, /api diteruskan ke FastAPI di :8000
npm run build        # type-check + build produksi ke dist/
npm run test:unit    # vitest
```
